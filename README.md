# Retail Sales Analytics Dashboard

## Overview
This project is an interactive Power BI dashboard designed to analyze retail sales performance and generate business insights.

## Features
- Total Sales KPI
- Total Orders KPI
- Total Customers KPI
- Total Products KPI
- Monthly Sales Trend
- Sales by Region
- Sales by Category
- Top 10 Products Analysis

## Tools Used
- Power BI
- Data Analytics
- Data Visualization
- Business Intelligence
